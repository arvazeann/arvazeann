# Profile README assets

- `assets/hero-terminal.gif` and `assets/matrix-rain.gif` are locally generated animations.
- `assets/hero-terminal.svg` and `assets/matrix-rain.svg` are image fallbacks used directly by `<picture>`; they are not displayed as links.
- `assets/ruanglagi-preview.png` and `assets/portfolio-preview.png` are screenshots from the public portfolio repository.
- `assets/terminal-divider.svg` and `assets/neon-footer.svg` are local decorative assets.
- `.github/workflows/snake.yml` generates the green contribution snake variants and publishes them to the `output` branch.
- `scripts/generate_assets.py` regenerates the terminal and matrix images. It requires Python 3 and Pillow.
- `scripts/update_active_project.py` uses GitHub's REST API to select the public repository with the most commits authored by `arvazeann` in the past 30 days. It creates `dist/active-project.svg` and updates the README's project link when the winner changes.

```bash
python -m pip install Pillow
python scripts/generate_assets.py
```

## Contribution snake

Push the repository to `main`, enable GitHub Actions, and allow the workflow to write repository contents. The workflow declares `contents: write` and publishes `github-snake.svg` and `github-snake-dark.svg` to the `output` branch. It runs on pushes to `main`, daily, or manually from the Actions tab.

The same workflow refreshes the active-project card daily. It uses the workflow's `GITHUB_TOKEN` to read public repository and commit data; no personal access token or extra setup is needed. The count covers commits attributed to your GitHub account on each repository's default branch. When a different repository becomes the most active, the workflow updates the README link to point directly to that repository. It only creates a README commit when that selected repository changes; the SVG count refreshes with the daily workflow.

## Rendering notes

- GitHub does not allow a README to set the full page background or run custom CSS/JavaScript. The portfolio look comes from local images, compact Markdown, and simple HTML tables.
- The profile links directly to the live portfolio and project demos; each was checked for an HTTP 200 response. Project source links go to the specific repositories.
- The contribution snake and active-project card are generated by GitHub Actions. No externally hosted statistics cards are used.
- Technologies are split between those visible in public projects and those currently being explored.
